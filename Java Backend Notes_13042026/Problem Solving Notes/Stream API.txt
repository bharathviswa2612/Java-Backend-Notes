12.Given a list of strings:
["Apple", "Banana", "apple", "banana", "kiwi"]
and an integer k = 2.
Write a Java program using Stream API to:
Convert all words to lowercase.
Count the frequency of each word.
Print the words whose frequency is exactly k.
Output should be in lexicographical order.
Expected Output:
apple
banana


List<String> input = Arrays.asList("Apple","Banana","apple","banana","kiwi");
int k = 2;

input.stream()
	 .map(String :: toLowerCase)
	 .collect(Collectors.groupingBy(Function.identity(),Collectors.counting()))
	 .entrySet()
	 .stream()
	 .filter(e -> e.getValue() == k)
	 .map(Map.Entry :: getKey)
	 .sorted()
	 .forEach(System.out :: println);
	 
incase of given array we can use Arrays.stream(input) , toArray(String :: new)

13.Top K frequent element 


input.stream()
	 .map(String :: toLowerCase)
	 .collect(Collectors.groupingBy(Function.identity(),Collectors.counting()))
	 .entrySet()
	 .stream()
	 .sorted(Comparator.comparing(Map.Entry :: getValue).reversed())
	 .map(Map.Entry :: getKey)
	 .limit(k)
	 .forEach(System.out :: println);
